# 06 設定與安裝

本 repo 的模型和影音工具都安裝在 Colab VM。使用者的電腦只安裝 Colab CLI 和一般開發工具，不需要 CUDA、NVIDIA 驅動、本機 ComfyUI 或模型權重。

## 本機控制端

Windows 的安裝、隔離環境、授權登入和常見錯誤，照 [跨電腦 Colab CLI 指南](../COLAB_CLI_跨電腦連線指南.md)。Linux 或 macOS 使用者可依 Google Colab CLI 的官方說明安裝相同 CLI；本 repo 的 Windows 修補程式只在 Windows 使用。

本機控制端只需：

- Python 3.12
- uv
- Git
- 網路連線
- 足夠空間放置專案素材與下載回來的成果

Google OAuth 授權碼只輸入啟動登入的 Terminal，不要交給 Codex 或貼進聊天。

## Colab VM

執行：

~~~powershell
python cloud/colab_h3.py check
python cloud/colab_h3.py start
~~~

start 會在 Colab 安裝完整流程所需的 ComfyUI、MiniMax H3、Qwen 生圖、聲音、配樂、中文字型和影音後製工具。通常新片使用完整安裝。只有在所有素材已準備好、只需 H3 渲染時才使用 --h3-only。

Colab VM 的工作磁碟是暫存空間。film 指令會上傳製片資料夾、在 Colab 執行 make_film.py，並將 out/ 同步回本機。請在 stop 前確認下載完整；不可把唯一本份成品留在 VM。

## 檢查與故障排除

可選擇在完整安裝後執行雲端 smoke：

~~~powershell
python cloud/colab_h3.py smoke
~~~

使用 session 時查看：

~~~powershell
python cloud/colab_h3.py status
~~~

完成下載後關閉：

~~~powershell
python cloud/colab_h3.py stop
~~~

出現額度、授權地區、Windows termios、連線逾時或授權碼問題時，依 [cloud/README.md](../cloud/README.md) 和 [跨電腦連線指南](../COLAB_CLI_跨電腦連線指南.md) 處理。
