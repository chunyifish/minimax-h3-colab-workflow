# 01 總覽與架構

## 目標

用 Codex 協助整理劇本與分鏡，並以 Google Colab 完成 AI 短片生成和後製。這份 repo 的唯一支援生成環境是 Colab；不要求使用者自備高階顯卡或安裝模型。

## 三層架構

~~~text
知識層
  根目錄 AGENTS.md、docs/、agent/skills/
  保存工作規則、劇本規範、生成檢查點與授權資訊

控制層：使用者工作區＋Codex
  編輯劇本與 film.json
  用 Colab CLI 上傳素材、呼叫遠端 stage、下載成果
  檢視每階段圖片、抽格、聽寫和成片

運算層：Google Colab VM
  安裝 ComfyUI、Qwen、聲音工具、MiniMax H3 和後製套件
  執行生圖、配音、影片、配樂、剪接、字幕與自審
~~~

## 預設工具

| 工作 | 工具與執行位置 | 說明 |
|---|---|---|
| 角色圖、場景圖、首幀 | Qwen Image／Qwen Image Edit，在 Colab VM | Codex 編輯提示詞，Colab 生成圖片 |
| 影片與動作音效 | MiniMax H3 Ref2VA，在 Colab VM | 由首幀、動作描述和角色參考音生成 |
| 角色參考音 | Breeze TTS 2，在 Colab VM | 每個角色設計一次；依模型授權使用 |
| 台詞備案 | BreezyVoice，在 Colab VM | 只在 H3 念錯或需精準聲畫同步時使用 |
| 配樂 | MiniMax Music 3，在 Colab VM | 使用純器樂描述並遵守模型授權 |
| 聽寫與自審 | faster-whisper、BS-RoFormer 和 repo 工具，在 Colab VM | 檢查台詞、雜訊、切點與音量 |
| 放大與組裝 | Lanczos 預設；必要時 FlashVSR，兩者都在 Colab VM |
| 工作控制 | OpenAI Codex＋Google Colab CLI | 本機是控制端；不需 Colab MCP |

## 執行邊界

- 所有模型推論和影音後製都在 Colab VM 執行。
- 本機工作區只管理文字設定、CLI、素材傳輸和成果檢視。
- 不提供本機 GPU 硬體分級、顯卡偵測或本機與雲端混合生成。
- Colab 額度、GPU 供應和價格會變動；開始前查看帳戶現況。
- MiniMax H3 有授權條件；若 Colab CLI 顯示地區或授權提醒，先停止並核對條款，不要繞過。

詳細步驟見 [02 端到端流程](02_端到端流程.md)，工作區需求見 [Colab 資源與本機需求](colab-resources.md)，CLI 操作見 [cloud/README.md](../cloud/README.md)。
