# 02 端到端流程

本流程所有模型和影音工作都在 Google Colab VM 執行。Codex 在工作區整理劇本、film.json 和素材，再用 Colab CLI 啟動遠端階段；CLI 會將 out/ 同步回影片資料夾供人工檢查。

## 流程總表

| 階段 | Colab 工作 | 本機檢查點 |
|---|---|---|
| 0. 題目與劇本 | Codex 整理題目、劇本和鏡表；不需 GPU | 使用者確認故事、角色和台詞 |
| 1. film.json | 整理角色、場景、提示詞、台詞和各鏡秒數 | 確認設定和授權素材 |
| 2. 文字讀本 | Colab 產生靜音讀本試映與每鏡時長估計 | 檢查節奏；劇本通過後才用模型額度 |
| 3. 角色與場景 | Colab 生成角色定妝照和場景母版 | 檢查外觀、服裝與空間方向 |
| 4. 首幀 | Colab 依角色參考照與場景圖生成每鏡首幀 | 檢查 out/first/_sheet.jpg；通過後才做 H3 |
| 5. 聲音與 H3 | Colab 生成角色參考音、H3 影片和需要的環境音 | 檢查逐鏡抽格、聽寫與嘴型 |
| 6. 配樂與後製 | Colab 生成配樂、字幕、片尾、剪接與放大 | 檢查配樂、音量、字幕和畫面 |
| 7. 自審與成片 | Colab 執行 review 工具並下載成品 | 播放完整影片，人工確認後交付 |

## 1. 準備新片

複製 pipeline/template_colab/ 到 pipeline/my_film/，編輯 film.json。模板包含角色、場景、首幀、聲音、每鏡動作、配樂和片尾設定。源素材須有合法使用權。

單鏡不超過 12 秒。每個 action 從首幀中的姿勢開始，依序描述動作起始、過程和結果；寫清楚身體部位、幅度和次數。

## 2. 在 Colab 先做文字讀本

完整安裝後先單獨執行讀本階段：

~~~powershell
python cloud/colab_h3.py film pipeline/my_film read
~~~

檢查同步回來的 out/preview/讀本試映.mp4 和讀本_timeline.json。此階段只排字幕與時長，不呼叫生成模型；Colab 工作階段仍依帳戶方案計算資源使用。劇本通過後才開始生成角色、場景和首幀：

~~~powershell
python cloud/colab_h3.py film pipeline/my_film chars masters frames
~~~

CLI 上傳製片資料夾，在 Colab 生成角色、場景和首幀，並下載 out/。使用者檢查 out/chars/、out/masters/ 和 out/first/_sheet.jpg。外觀、場景或構圖不合格時，修改 film.json 的提示詞或 seed，再重跑相同階段。

## 3. 在 Colab 生角色、場景和首幀

文字試映通過後執行前述 `chars masters frames` 指令，確認同步回來的角色圖、場景母版和 out/first/_sheet.jpg。

## 4. 在 Colab 生聲音與影片

首幀通過後執行：

~~~powershell
python cloud/colab_h3.py film pipeline/my_film voices h3 amb
~~~

預設由 H3 使用角色參考音念台詞。沒有台詞的臉部鏡頭使用靜音引導，避免模型自行說話。完成後檢查 out/review/clips_*.jpg、每鏡影片和聽寫結果。重拍時調整 seed；只重跑指定鏡頭可加 --env ONLY=S03。

## 5. 在 Colab 後製與自審

逐鏡確認後執行：

~~~powershell
python cloud/colab_h3.py film pipeline/my_film edl music ending cut review
~~~

主要工作包括依時間軸剪接、配樂、音效、字幕、片尾、1080p 成片和手機版輸出。Colab 會把 out/ 同步回工作區。最後播放 out/cut/film_1080p.mp4，檢查台詞、音量、字幕、黑畫面、定格、切點和片尾。

## 6. 工作階段與檔案

可用 python cloud/colab_h3.py status 查看工作階段；同一部片的多個 stage 可在完整環境已安裝後接續使用。完成下載後執行 python cloud/colab_h3.py stop。重要素材和成果要保存在工作區，Colab VM 關閉後暫存磁碟會清除。

所有 Colab 操作、額度和錯誤處理見 [cloud/README.md](../cloud/README.md)。範本欄位見 [pipeline/template_colab/README.md](../pipeline/template_colab/README.md)，自審標準見 [04 自審清單](04_自審清單.md)。
