# 生成前文字試映與 Colab 畫面檢查

> 目的：在模型生成前，先讓使用者**讀一遍台詞與節奏**，抓出「節奏太快」「轉折沒交代」「片長超標」。由 Colab `read` stage 輸出試映；角色圖、場景圖和首幀生成後，再看同步回來的 `out/first/_sheet.jpg`。
> **2026-10-23 起讀本只給文字、不先做 TTS**：台詞之後由 H3 拿角色參考音自己念（`docs/02` §6），讀本聲音用不到成片裡；片長與每鏡 H3 長度改用字數估。要先「聽」一遍才做 TTS 讀本（第 5 節）。
> 試映素材只給使用者內部看，不上片。輸入和結果放 `<片資料夾>/out/preview/`；stage 完成後 CLI 會同步回工作區。

## 0. 編輯 `film.json` 並啟動 Colab 試映

確認每鏡的 `dur` 和 `line` 後，在工作區呼叫：

```powershell
python cloud/colab_h3.py film pipeline/<片名> read
```

`make_film.py` 會從 `film.json` 產生 `out/preview/shots.json`，再由 Colab 輸出試映與時長估計。確認劇本後才啟動耗用模型額度的角色、場景與影像生成階段。

## 1. 查看 Colab 產生的文字讀本試映

- Colab 依鏡表排時間軸 → `out/preview/讀本試映.mp4`（720×1280，深色卡片顯示鏡號與字幕；**靜音**，每句照一般語速每秒 4 字停留）＋`out/preview/讀本_timeline.json`（每鏡起訖秒數、台詞字數 `chars`、建議 H3 鏡長 `h3_sec`）。CLI 會將結果同步回工作區。
- **H3 鏡長用 `h3_sec`**＝max(3 秒, 鏡表秒數, 台詞字數 ÷ 3＋2 秒)，取到 0.5 秒；字數＝中文字＋英數字，不含標點。
  - 依據（原頻道〈颱風假作業包〉）：H3 用參考音自己念，每秒約 2.3–4.7 字，而且 14 句裡有 5 句晚 1.5–2.1 秒才開口；用這個公式，開口時間可靠的 7 句全部在鏡頭內念完（最緊的 13 字句算出 6.3 秒、實際念到 6.16 秒）。
  - 估長一點沒關係：剪接時照 H3 實際開口時間裁掉空白，只是多花一點生成時間。`h3_sec` 超過 12 秒的鏡要拆。
- 回報：**估計總長 vs 目標**、最長的三鏡、超出鏡表秒數的鏡、要拆的鏡。

## 2. 給使用者的試映包

- 試映影片＋一張表（鏡號／估計秒數／台詞），標出你自己覺得可能太快、沒講白的地方，請使用者看的時候特別注意。
- 說明：這是文字讀本，沒有聲音；語氣、停頓等成片出來再看，念錯的句子那時再修。
- 超長就**刪台詞或併鏡**，不要加速。使用者說「通過」才進首幀。

## 3. 之後的聲音流程（H3 階段）

- 每個角色一份參考音（你有權使用的真人錄音，10–20 秒、乾淨、平常講話語氣），定了就不換。角色要吼、喊口令的戲，**另錄一份兇的參考音**（平常語氣的參考音念兇的口令會偏溫和）。
- H3 spec 寫 `audio.voice_ref`；兩三人對話同鏡就寫 `audio.voice_refs`（各給參考音，最多 3 位）；鏡長用 `h3_sec`。
- 跑完聽寫比對原文 → 念錯／改用詞的換 seed 再抽 2 次 → 還是錯：**請配音的人錄那一句**，當固定音軌（`audio.fixed`）給 H3 對嘴、只重跑那一鏡；無法錄音時，在 film.json 將該句設為 fixed，透過 Colab 的 voices stage 生成固定音軌。
- 寫劇本時就避開 H3 容易改掉的說法（例：「二十四號」會被念成「二十四日」）。

## 4. （選用）TTS 讀本：使用者要先「聽」一遍時才做

- 備案配音使用該角色**定稿參考音**（`ref_audio`＋`ref_text`），可在 film.json 將個別台詞設為 fixed，再由 Colab 的 voices stage 生成和挑選。不要在本機執行 BreezyVoice 或 Breeze 模型。
- 把挑中的音檔在 `film.json` 設為 fixed 配音後，由 Colab `voices` stage 生成和挑選；不在工作區製作試映影片。
- **念錯的字要修**（讀本是使用者第一次聽到台詞，念錯會被當成劇本問題）：
  - 例：Breeze 會把「颱風」的「颱」念成四聲（像「泰」）→ 配音輸入寫「**抬**風」（字幕照原字）。「防災」被念成「放發」→ 輸入「防**栽**」。
  - 聽寫（ASR）只驗字、不驗聲調：關鍵字要量音高曲線（`tools/pron_check.py`），二聲要「從低處上揚」，判 unsure 就當不合格。
  - 修過的讀音記進你自己的讀音修正表，下一支片先查。
- 配音工具若用名稱快取（同名候選會跳過），換了輸入文字要**換 job 名稱**，不然拿到的還是舊音檔。
