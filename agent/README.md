# agent：Codex 協作檔案

| 檔案 | 用途 |
|---|---|
| AGENTS.md範本.md | 單支影片專案的 Codex 入口；複製到該影片資料夾並命名為 AGENTS.md |
| skills/codex-ai-drama/ | 給 Codex 使用的編劇技能與劇本檢查表 |

本 repo 的直接指示在根目錄 AGENTS.md。所有模型生成與後製都透過 Colab CLI 在 Colab VM 執行。Codex 的工作是協助整理劇本和設定、呼叫雲端工作、檢查同步回來的結果。

劇本技能源自原作者資料，請保留其 NOTICE.md 與授權資訊。現行執行方式以 README、cloud/README 和 pipeline/template_colab/README 為準。
